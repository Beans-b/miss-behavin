AEO page-type checklists (v2)

Binary checks by page type — report "X of Y passing," never a score with no data source. Composite AI scores (retrieval, confidence, readability) are banned here: no instrument measures them.

Collection pages

  • First paragraph answers the page query in 40–60 words (decisions 27/53)
  • Copy splits at the first closing p tag — one field, intro above grid, rest below
  • Q&A collapsed in details blocks below the grid — visible text, no FAQPage schema (decision 8)
  • One H1, self-canonical, CollectionPage + BreadcrumbList present
  • NO word-count target — 150-word tripwire only (decision 20)

Product pages

  • Feed attributes complete — the 13-field KPI A definition (08-21)
  • Photos published (no photos, no website — decision 16) + alt text + descriptive filename
  • Description present and honest; category from the taxonomy tree, never suggested
  • Product/Offer schema is PLATFORM-GENERATED — never hand-edit (decision 55); returns + shipping route through Merchant Center
  • Titles never change — tied to POS (decision 2)

Informational pages (blog, guides, About)

  • Question-phrased H2 + 40–60 word direct answer under it
  • One concrete number + one quotable staff line per post
  • Sophie byline + visible date; two internal links same day
  • Build informational answers for Google surfaces first (decision 47 as amended 08-22; ChatGPT re-test Nov 2026)
  • No fabricated metrics — placeholders over invented numbers, everywhere
